# Marlyn & Tihomir Wedding Invitation — GitHub Pages package

## Files
- `index.html` — the invitation webpage
- `assets/` — extracted image files referenced by the HTML

## Publish with GitHub Pages
1. Create a repository named `wedding-invitation` (or your preferred name).
2. Upload `index.html` and the entire `assets` folder, preserving this folder structure.
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/(root)`, then save.
5. Wait for the Pages deployment to finish and open the URL shown in Settings → Pages.

Do not upload only `index.html`: the extracted images must remain inside the adjacent `assets/` folder.
